# Geometria Analítica

⚠️ Subdiretório em construção... ⚠️

Neste subdiretório, se encontram notas de aula pessoais baseadas
no curso de Geometria Analítica, ministrado pelo Prof. Eduardo Wagner. 
Eu recomendo que o meu material seja usado unicamente como um material 
complementar, o material principal deve ser as notas de aula que o 
professor disponibiliza no EClass. O meu material não tem a intenção 
de substituir as notas de aula oficiais, o seu único propósito é o de 
servir como um complemento.

De igual modo, eu recomendo fortemente que as listas de exercícios 
do professor sejam feitas. Elas sempre trazem as respostas ao final, 
mas não olhem as respostas antes de tentar fazer os exercícios, apenas 
as usem para conferir os resultados, ou no caso de ficarem travados por 
muito tempo em um problema.

É possível que eu faça alguns comentários sobre Álgebra Linear no final 
das notas, cobrindo, possivelmente, alguns conteúdos que estão fora do escopo 
dessa disciplina. Eu recomendaria que esses conteúdos extras fossem lidos após 
a semana de A2, já como uma preparação para o curso de Álgebra Linear do próximo 
semestre.

Eu pretendo escrever as notas seguindo a sequência do curso, então elas podem 
ser lidas de maneira linear sem problemas.

Se encontrar algum erro, sinta-se à vontade para abrir um Pull Request
com as devidas modificações.
