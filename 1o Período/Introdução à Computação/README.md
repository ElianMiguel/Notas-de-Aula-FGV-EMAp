# Introdução à Computação

⚠️ Subdiretório em construção... ⚠️

Neste subdiretório, se encontram notas de aula pessoais baseadas
no curso de Introdução à Computação, ministrado pelo Prof. Alexandre 
Rademaker. Haverá uma diferença importante entre o meu material e o 
material usado nas aulas: durante as aulas, vocês aprenderão alguma 
linguagem de programação (no meu ano, por exemplo, foi a linguagem C, 
e no final do curso, Lean). O meu material, por sua vez, focará em 
ensinar conceitos de lógica de programação, mas não usará nenhuma 
linguagem específica (eu o farei em pseudocódigo).

De igual modo, eu farei uma introdução à análise de complexidade de 
algoritmos, de modo que a minha intenção com este material seja dar 
uma base teórica para a Programação (1º e 2º períodos) e também para 
o estudo de Estruturas de Dados e Algoritmos (3º período).

Eu recomendo fortemente que façam os trabalhos e os laboratórios, 
e, de igual modo, que participem ativamente das aulas.

Se encontrar algum erro, sinta-se à vontade para abrir um Pull Request
com as devidas modificações.
