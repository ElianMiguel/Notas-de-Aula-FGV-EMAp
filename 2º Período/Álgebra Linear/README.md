# Álgebra Linear

⚠️ Subdiretório em construção... ⚠️

Neste subdiretório, se encontram notas de aula pessoais baseadas
no curso de Álgebra Linear, ministrado pelo Prof. Guilherme Tegoni Goedert. 
Este material é baseado principalmente nos slides feitos pelo 
Prof. Yuri Fahham Saporito, que ministrava esta matéria até 2024,
mas cujos slides são seguidos pelo professor. De todo modo, as minhas 
notas de aula devem ser utilizadas apenas como um complemento ao 
livro-texto, que é "Álgebra Linear e suas Aplicações", de Gilbert Strang.

Álgebra Linear é uma matéria muito abstrata em comparação com as disciplinas
do 1º período, então eu recomendo fortemente que dediquem uma boa parte do 
tempo a ela, e sobretudo, eu recomendo que façam vários exercícios, não 
apenas das listas oficiais, como também recomendo que procurem outros 
exercícios em vários livros diferentes de Álgebra Linear.

Uma recomendação pessoal minha de livro é o "Linear Algebra Done Right", 
de Sheldon Axler, que possui um ótimo embasamento teórico e exercícios 
bastante interessantes. A abordagem do livro é bem diferente da abordagem 
da disciplina, mas eu o considero um ótimo complemento.
